User Manual

How to install and use INFO-JARVIS, step by step.

Download

Click the download button and save INFO-JARVIS-Setup_1.exe.

Install

Double-click the file, choose Next through the wizard, then Install.

Launch

Open INFO-JARVIS from the Start menu or the desktop shortcut.

Allow microphone

If Windows asks for microphone access, choose Allow.

Give commands

Speak or type a command, for example "open YouTube".

Commands you can try

Open apps and websites
  • Open Notepad, Open Calculator
  • Open YouTube, Open Google
Windows settings
  • Open Wi-Fi settings, Open display settings
System information
  • Tell me the time, System information

These are example commands. Edit this list to match the exact commands your version of INFO-JARVIS understands.

Requirements

What you need
  • A Windows PC (Windows 10 or 11 recommended)
  • A working microphone for voice commands
  • An internet connection for commands that open websites

Troubleshooting

Windows says "Windows protected your PC"

This appears for new apps that are not yet code-signed. Click More info, check the file name is INFO-JARVIS-Setup_1.exe, then click Run anyway.

My antivirus blocks or deletes the file

Voice and automation apps can be flagged by mistake. Compare the file's SHA-256 with the one shown above (PowerShell: Get-FileHash INFO-JARVIS-Setup_1.exe). If they match, it is the original file.

Jarvis cannot hear me

Go to Windows Settings → Privacy → Microphone and allow desktop apps. Check the correct microphone is selected in Sound settings and not muted.

How do I uninstall it?

Open Windows Settings → Apps → Installed apps, find INFO-JARVIS and choose Uninstall.
